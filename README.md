# 🎵 Neoma Beats (Android & Web)

> **Ad-free, Lossless Music Streaming Powered by Neoma Hub.**

Neoma Beats is a custom ad-free music streaming client with a high-fidelity Spotify-inspired UI, background playback, synchronized karaoke lyrics, and offline playback capabilities.

### 🌟 Features
- **100% Ad-Free**: Enjoy your favorite music without commercial interruptions.
- **Background Audio**: Seamless audio playback with screen locked.
- **Synchronized Lyrics**: Real-time karaoke lyrics powered by LRCLIB.
- **Offline Mode**: Save songs directly to your device for on-the-go listening.
- **Synced with Neoma Web**: Access the web player anytime at `https://beats.neoma.space`.

### 🚀 Download APK
Grab the latest release APK from the [Releases](https://github.com/errorcript/neoma-beats/releases) section or install via [beats.neoma.space](https://beats.neoma.space).
